# Kono Pizza 🍕

A bold, premium pizza ordering landing page for **Kono Pizza**.

## What's included
- Responsive one-page website
- Red / blue / green visual system
- Bold pizza-chain-inspired menu layout (original Kono branding)
- Animated entrance and scroll reveals
- Deals section
- Menu filtering: Pizza / Sides / Drinks
- Working front-end cart drawer
- Add-to-cart interactions and totals
- Mobile-friendly layout
- No build step required

## Run it
Just open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save. GitHub will publish the site.

## Make it production-ready
The checkout is intentionally a front-end demo. Connect the `checkout` button in `script.js` to your real ordering/payment system (for example Stripe Checkout or your own ordering API).

### Easy edits
- Menu items: edit the cards in `index.html`.
- Prices: change `data-price` and the displayed price.
- Brand colours / layout: edit variables or selectors in `styles.css`.
- Cart/order behaviour: edit `script.js`.
